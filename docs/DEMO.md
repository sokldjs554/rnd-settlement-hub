# 5분 데모 시나리오

면접·시연용 스크립트. 사전 준비: `docker compose up --build` 후
`docker compose exec api python -m app.seed --demo` 실행, http://localhost:3000 접속.

계정(비밀번호 공통 `demo1234!`): `researcher@demo.kr` / `manager@demo.kr` / `admin@demo.kr`

## 0:00 — 문제 한 줄 (말로)

> "국가 R&D 연구비는 규정 위반 시 환수·제재로 이어지는데, 제출 전 검증이 전부 엑셀 수작업입니다.
> 그 검증을 AI+룰 엔진이 먼저 하고 사람이 결정만 하게 만든 시스템입니다."

## 0:30 — 연구원: 집행 등록 → 제출

1. `researcher@demo.kr` 로그인 → 집행 건 → **집행 등록**
2. 과제 선택, 비목 `연구재료비`, 제목 "시약 구입", 금액/일자 입력, 증빙 PDF 첨부
   - 포인트: **일부러 흠 있는 데이터**를 넣으면 극적이다 — 예: 주말 날짜,
     이미 시드된 건과 동일한 거래처+금액+일자(중복 의심), 폐업 사업자번호(NTS 키 있을 때)
3. "등록하고 제출" → 상세 화면: "자동 검증 파이프라인 실행 중" 배너

## 1:30 — 자동 파이프라인 (기다리는 동안 설명)

> "제출과 동시에 DB 큐에 작업이 들어가고 워커가 SKIP LOCKED로 집어갑니다.
> AI가 증빙에서 거래처·금액·사업자번호를 추출하고, 15개 룰이 대사·기간·예산·휴폐업을
> 검사합니다. AI가 죽어도 룰 검증만으로 계속 가고, 수기 대조 플래그가 남습니다."

수 초 후 화면이 자동 갱신되어 **검토 대기** + 검증 결과 목록이 나타난다.

- 보여줄 것: 3단 대조(입력값 ↔ AI 추출값), 위반/주의 배지, 룰 코드별 근거 데이터

## 2:30 — 담당자: 검토 → 승인

1. 로그아웃 → `manager@demo.kr` 로그인 → 알림 벨(검토 대기 알림) → 해당 건
2. FAIL이 있는 건이면 **승인이 막히고 override+사유**를 요구하는 것을 보여준다
   - 포인트: "차단이 아니라 차단 권고 — 현실 업무의 예외를 인정하되 감사 기록을 남깁니다"
3. 승인 → 처리 이력 타임라인 확인 (등록→제출→검증→승인 전 과정)

## 3:30 — 월별 보고서

1. 정산보고서 → **월별 보고서 생성** (과제/월 선택)
2. 집계표(비목별 예산·당월·누적·잔액) 즉시 표시 — "이 숫자는 전부 SQL입니다"
3. 서술부에 AI 초안이 채워지는 것 확인(키 있을 때) — "초안임이 명시되고 담당자가 수정 후 확정"
4. 확정 누르면 포함된 집행 건이 잠기는 것 설명

## 4:30 — 대시보드 (관리자 관점 마무리)

- 검토 대기·비목별 예산 소진(80% 경고)·룰 위반 Top 5
- **AI 지표**: 추출 성공률, 제안 채택률 — "AI를 신뢰할 수 있는지도 데이터로 감시합니다"
- 자동화 Before/After — "수기 15분/건은 가정값으로 명시했고, 파이프라인 시간은 실측입니다"

## 예상 질문 대비

- 동시 승인으로 예산 초과? → 예산 행 FOR UPDATE 잠금, 동시성 테스트로 재현·검증
- AI가 금액을 잘못 읽으면? → 판정은 룰이 함 (불일치 FAIL) + confidence 낮으면 수기 대조 플래그
- 외부 API 다운? → 캐시 폴백/미확인 플래그, 워크플로 무중단
- 작업 중복 실행? → idempotency key UNIQUE + 상태 검사 + SKIP LOCKED
